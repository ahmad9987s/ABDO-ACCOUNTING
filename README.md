# ABDO Restaurant — النظام المحاسبي (نسخة الملفات المنفصلة)

برنامج محاسبي ونقطة بيع لمطعم برجر، واجهة عربية (RTL) بالأحمر والأسود والأبيض، تعمل على المكتب والجوال.

## التشغيل
1. افتح `index.html` بالنقر المزدوج في Chrome أو Edge. لا يحتاج تثبيتاً ولا إنترنت (المكتبات داخل مجلد `lib/`).
2. الدخول الأول: `ADMIN` / `ADMIN` — **غيّر كلمة المرور فوراً** من الإعدادات ← المستخدمون.

**ترتيب تحميل ملفات js مهم** — هي سكربتات عادية تتشارك المتغيرات العامة، فلا تغيّر ترتيبها في `index.html`.

## أين تُحفظ البيانات؟
في متصفح الجهاز (localStorage). **لا توجد مزامنة بين الأجهزة في هذه النسخة.**
- خذ نسخة كاملة أسبوعياً: الإعدادات ← البيانات والنسخ الاحتياطي ← تنزيل نسخة (JSON)، وتُستعاد من نفس الصفحة.
- مسح بيانات المتصفح يحذف البيانات؛ والنسخة الاحتياطية هي الحماية.
- لنقل البيانات بين جهازين: نسخة JSON، أو Excel من أزرار كل صفحة.
- ملاحظة: الكود يحتوي أيضاً على طبقة مزامنة لقاعدة بيانات claude.ai، وهي لا تعمل خارجها ولا تؤثر في هذه النسخة.

## الطباعة
في نافذة طباعة المتصفح: الطابعة 80mm، حجم الورق بالرول المستمر (مثل `80(72.1) x 99999 mm`)، الهوامش: بدون، المقياس 100%، وأوقف الرؤوس والتذييلات. لإلغاء نافذة الطباعة نهائياً شغّل Chrome/Edge بالمعامل `--kiosk-printing`.

## النشر على الإنترنت (استضافة ثابتة)
ارفع **مجلد `abdo-accounting` كاملاً** (بما فيه js و css و lib) على أي استضافة ملفات ثابتة مثل Netlify Drop أو Cloudflare Pages أو GitHub Pages. تذكّر أن البيانات تبقى في متصفح كل جهاز (انظر أعلاه). ولأن الدخول داخل الصفحة نفسها فلا يُعدّ حماية حقيقية: لا تضع بيانات حساسة على رابط عام دون خادم وتسجيل دخول حقيقيين.

## ملف SQL
`database/schema.sql` مخطط MySQL 8 مكافئ لبنية بيانات البرنامج (مستخدمون وصلاحيات، شجرة حسابات، أطراف، أصناف، طرق دفع، مبيعات وبنودها، حركات، عروض للأرصدة والديون والمبيعات اليومية).
**البرنامج لا يتصل به حالياً**؛ هو أساس لبناء خادم (PHP أو Node.js) يربط الواجهة بقاعدة بيانات. تحققت من سلامة صياغته فقط ولم أشغّله على خادم MySQL فعلي.

## أمان
كلمات المرور في هذه النسخة تُحفظ داخل بيانات المتصفح بنص عادي، والصلاحيات تنظّم الواجهة ولا تمنع مستخدماً تقنياً. للحماية الحقيقية يلزم خادم مع تسجيل دخول ومصادقة.
